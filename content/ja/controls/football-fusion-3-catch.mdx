## 全プラットフォーム対応：キャッチ操作一覧

Football Fusion 3で正確なレセプションを決めるには、的確なボタン入力とカーソルの追従（トラッキング）が不可欠です。アーケードスタイルのフットボールゲームとは異なり、本作ではマウスの配置やカメラの向きによってプレイヤーのリーチやジャンプ軌道が大きく左右されます。

以下は、PC、Xbox/PlayStationコントローラー、モバイルタッチスクリーンの全入力対応表です。

### プラットフォーム別入力概要

| アクション / キャッチタイプ | PC (キーボード & マウス) | Xbox コントローラー | PlayStation コントローラー | モバイル (タッチスクリーン) |
| :--- | :--- | :--- | :--- | :--- |
| **スタンダードキャッチ** | 左クリック (LMB) | 右トリガー (RT) / X | R2 / □ボタン | 「Catch」ボタンをタップ |

### キャッチ感度とカメラ設定

コミュニティの検証によると、マウスやスティックの感度はキャッチ範囲（キャッチ半径）に劇的な影響を与えます。飛来するスパイラルパスを追う際、プレイヤーの手は照準（クロスヘア）またはカメラの中心に向かって伸びます。

*   **PC マウスDPI:** ボールの弾道を追い越しすぎず、スムーズにカメラを振るために 800〜1200 DPI を推奨。
*   **コントローラーのデッドゾーン:** ボールがリーチ内に入った瞬間に即座に反応できるよう、デッドゾーンは 5%〜10% に設定。
*   **カメラ距離:** ディフェンシブバック（DB）の位置取り（ヒップレバレッジ）とボールの放物線の両方を捉えられるよう、カメラズームは少し引いた状態に設定。

## Football Fusion 3 主要キャッチタイプの解説

ボールの位置や守備のカバー状況に応じてどの**Football Fusion 3 キャッチ**モーションを発動すべきかを理解することで、パスドロップ率を劇的に下げることができます。ゲームエンジンは、ボールの速度、手とボールの接触タイミング、プレイヤー同士の衝突をリアルタイムで計算し、キャッチ成立を判定します。

```
                   [ キャッチ選択ツリー ]
                             |
        -------------------------------------------------
        |                       |                       |
   [高め / DBの上]         [低め / 落ちる球]       [胸元 / オープンフィールド]
        |                       |                       |
 ハイポイントキャッチ       ダイビングキャッチ       セキュア / RACキャッチ
(ジャンプ + タイミング)    (前方跳躍 / スライド)      (捕球後そのまま疾走)
```

### キャッチタイプ比較表

| キャッチタイプ | 最適なルート / 状況 | 入力タイミング | リスク | 獲得ヤード期待値 |
| :--- | :--- | :--- | :--- | :--- |
| **RAC (ラン・アフター・キャッチ)** | スラント、ドラッグ、フラットルート | フルスプリントを維持しながら捕球 | 低 | 高 (勢いを維持) |
| **ハイポイント (アグレッシブ)** | フェード、レッドゾーンの競り合い、ディープポスト | ボールの頂点で跳び、最高到達点でキャッチ | 中〜高 | 中 (前進の勢いは停止) |
| **ポゼッション / ローキャッチ** | カムバック、カール、サイドライン際 | しゃがみ/減速 + 地面付近で捕球 | 低 | 低 (接触で即ダウン) |
| **ダイビングキャッチ** | オーバー気味のディープパス、密集したシーム | 最適な弾道角度へ向かって前方にダイブ | 高 | 高 (ハイライト級のビッグプレー) |
| **ワンハンド・スペックキャッチ** | 高OVRかつリーチスタッツ最大時 | ギリギリのリーチ範囲で自動発動 | 極めて高い | 変動 |

### 1. RAC（ラン・アフター・キャッチ）テクニック
RACキャッチは、レシーバーが減速したり長いキャッチアニメーションに固定されたりすることなく、前進の勢いをそのまま維持できる技術です。成功させるには、スプリントラインの少し前方にボールを捉え、ボールが胸に届く直前にキャッチを入力します。これによりCBの追従を振り切り、独走タッチダウンへと繋げることができます。

### 2. ハイポイント・キャッチ（最高到達点での捕球）
クォーターバック（QB）がダブルカバーの中に高いディープパスを放り込んだ場合、通常のキャッチを試みるとスワット（叩き落とし）やインターセプトを食らうリスクが高まります。ボールが届く少し前にジャンプし、ジャンプの最高到達点でキャッチを入力することで、ディフェンス陣の上から垂直方向のスペースを確保できます。

## キャッチタイミングと当たり判定（ヒットボックス）のステップ解説

安定して**Football Fusion 3 キャッチ**を成功させる鍵は、アバターの周囲に存在する見えないキャッチ判定（キャッチレディアス）を理解することです。ゲームは「ボールとの距離」「手とボールの角度」「キャッチフレーム中に守備の接触（タックルやスワット）を受けているか」の3つの重要要素を判定します。

### キャッチ成功率を最大化するステップ

1. **ボールマーカーを素早く確認:** QBの手からボールが離れた瞬間から、放物線の軌道と落下地点の影を注視する。
2. **インサイド/アウトサイドのレバレッジを確保:** 飛来するボールとDBの間に自分のレシーバーを位置取らせ、体でボールをスクリーン（遮蔽）する。
3. **照準を合わせる:** カメラを操作し、クロスヘアをボールの先端に直接合わせる。
4. **入力のタイミングを測る:** 緑色のタイミングウィンドウ内（着弾の約0.15〜0.3秒前）でキャッチを発動する。
5. **捕球後のボールプロテクト:** 捕球後はすぐにフィールド上方へ体を向けるかボールを抱え込み、追走してくるラインバッカー（LB）によるファンブル誘発を防ぐ。

### よくあるタイミングミスと解決策

| 問題点 | 主な原因 | 改善策 |
| :--- | :--- | :--- |
| **ポロポロ落とす（バターフィンガー）** | ボールが当たり判定に入る前に入力するのが早すぎる | ボールがプレイヤー1〜2体分の距離に近づくまで待ってからタップする。 |
| **叩き落とされる（スワット）** | ジャンプするDBに対して足を止めた状態で捕球しようとしている | 地上で待たず、「ジャンプ + キャッチ」でハイポイントキャッチを狙う。 |
| **ボールを通り越してしまう** | ボールの落下地点を勢い余って走り抜けている | スプリントボタン（Shift）を離して微調整を行う。 |
| **アウト・オブ・バウンズ（枠外捕球）** | ディープロート中にサイドラインの外へ流れてしまう | ポゼッションキャッチを使い、境界線際でつま先を残す（トータップ）。 |

## レシーバーのスタッツ基準と99 Overallの達成条件

キャッチの成否はプレイヤーの操作技術だけでなく、ゲーム内スタッツの数値にも大きく左右されます。[RobloxのFootball Fusion 3](https://www.roblox.com/games/82866880824588/Football-Fusion-3)でエリートの証である総合値「99 OVR」プレイヤーを作成するには、公式の厳格な基準をクリアしなければなりません。

最大のスタッツ評価を獲得して99 OVRビルドに到達するには、高い平均獲得ヤードに加え、**ターゲットに対するキャッチ率50.0%以上**という厳しい条件を満たす必要があります。

### 99 OVRに必要な目標パフォーマンス指標

| パフォーマンス指標 | 必要とされる基準値 | プレイヤー評価への影響 |
| :--- | :--- | :--- |
| **キャッチ / ターゲット率** | **最低 50.0%** | 極めて重要 (WR評価に直結) |
| **キャッチ平均獲得ヤード** | 13ヤード以上 | 高 (ビッグプレーの創出能力) |
| **クォーターバックレーティング (QBR)** | 88以上 | デュアルスレット型ビルドで重要 |
| **ディフェンシブブレイクダウン (DBR)** | 90以上 | 守備パフォーマンス指標 |
| **ターンオーバー / タックル (TPG)** | 7+ TPG | 攻守兼任およびセカンダリー指標 |
| **フィールドゴール / キック精度** | 60%以上 | スペシャルチーム評価 |

*注：ゲームのアップデート情報によると、これらの基準を超えて最大XPに達しても、初回の挑戦で必ず99 OVRになれるとは限りません。再挑戦のためにビルドを「プレステージ（Prestige）」する必要がある場合もあります（VIP特典により98から99 OVRへのブーストも存在します）。*

## 高度なキャッチ戦略とルートランニング

邪魔されることなくフリーで**Football Fusion 3 キャッチ**を決めるには、パスが投げられる前の段階でセパレーション（守備との距離）を作っておく必要があります。キレのあるルートカットと的確なボールトラッキングを組み合わせることで、ディフェンスにとってアンストッパブルな存在になれます。

### ルート別解説と最適なキャッチウィンドウ

| ルート名 | ブレイクポイント (ヤード) | 最適なキャッチスタイル | 主な対策対象 |
| :--- | :--- | :--- | :--- |
| **スラント** | 3–5 ヤード | RACキャッチ | プレスマンカバー |
| **ポスト / コーナー** | 10–15 ヤード | ハイポイント / ショルダー越し | カバー2 / カバー3 セーフティ |
| **ストリーク / ゴー** | 垂直 / ディープ | ダイビング または ランニングスペック | オフマン / ベイルテクニック |
| **カール / ヒッチ** | 7–10 ヤード | ポゼッション（ローポイント）キャッチ | 下がり目のゾーンLB |
| **アウト / ディグ** | 8–12 ヤード | サイドライン際のトータップポゼッション | フラットディフェンダー / ニッケルバック |

### ディフェンスにおける「スワット vs キャッチ」の判断
ディフェンシブバックやセーフティとしてプレイする場合、インターセプトにもオフェンスと同様のポジショニング技術が求められます。しかしコミュニティの検証によると、キャッチスタッツが格段に高いレシーバーに対して競り合いでインターセプトを狙うと、競り負けてしまうことがあります。第4クォーターなどでリードを守り切りたい状況では、右クリック（RMB）でスワット（叩き落とし）を選択する方が、キャッチ＆ランによる失点リスクを最小限に抑えられます。

## よくある質問（FAQ）

### 密集地帯（トラフィック）で最も確実にFootball Fusion 3 キャッチを決める方法は？
最も確実な方法は、ディフェンダーの進路の前にレシーバーを割り込ませ、ボールが届く直前にジャンプして「ハイポイントキャッチ」を実行することです。これにより、ディフェンスのスワット判定から逃れ、最高到達点で安全にボールを確保できます。

### Football Fusion 3でパスを落としてしまう（ドロップする）理由は？
主な原因は、入力タイミングのズレ、DBから直接接触を受けている最中の捕球、またはキャッチスタッツの低さです。ボールが手に届く0.2秒前を目安に入力し、焦ってキャッチボタンを連打しないように注意してください。

### Football Fusion 3で99 Overallに到達するために必要なキャッチ率は？
他のスタッツ基準（平均獲得13ヤード以上や各種高レート評価など）を満たした上で、最低でも**キャッチ/ターゲット率50%**を維持する必要があります。達成できなかった場合は、プレイヤーをプレステージしてリセットし、再挑戦する必要があります。

### モバイルでもダイビングキャッチは可能ですか？
はい、可能です。モバイル端末では、着地点に向かってスプリントしながら「Dive」アイコンをタップし、素早く「Catch」ボタンをタップします。最大限のリーチを引き出すため、カメラの角度をボールの軌道にしっかり固定してください。
